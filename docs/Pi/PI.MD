# Raspberry Pi Setup

## Hardware used:
- Raspberry Pi 4b (4GB RAM)
- 2x Raspberry Pi Camera Module 2 (8MP)
- Arducam Multi Camera Module 2.1

## Setup Process:
1. Download copy of os to sd card and set up pi with password
2. Create an ssh key to allow for access to the github repo
3. Download relevant libraries for the camera adaptor board
4. Allow SSH connections to the Pi
