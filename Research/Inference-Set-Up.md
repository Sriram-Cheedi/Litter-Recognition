# Inference Set Up Guide
## Preliminary Details:
After struggling for a long while to build an object detection model using the TACO dataset, we came across a model at the [weblink](https://www.kaggle.com/code/bouweceunen/garbage-detection-with-tensorflow). We decided on using this model as it skips past the training stage that we did not have enough knowledge to do and the model is licensed under Apache 2 meaning that it is open-source.

Now that we had the model, we set out to integrating it into our Raspberry Pi 4...

## Reconstructing the Frozen Graph
As the .pb detection file we had obtained was incomplete, we had to adapt code found at the previous link into a program that would translate the .pb file into our usable frozen graph. This code can be found at code/graphReconstructer.py in our repository.

Part of the motivation for doing this in our file system rather than live in the code was to be able to convert the model into tensorflow lite format. This would ensure the model would be a lot more lightweight in order for it to be used on our Raspberry Pi.
Another reason is that it will simplify our inference script once it is written to work with the picams.

## Converting to a TFLite Model
In order to convert from a .pb model to a .tflite model, we needed to know the names of the input and output tensors of the model. 
To achieve this, we used code generated by ChatGPT that would allow us to inspect the tensors of the model. We also used Netron to visualise the model and its tensors.


```
# Code sourced from ChatGPT
# Code inspects the tensors of a frozen graph .pb model

import tensorflow as tf

def inspect_pb_graph(pb_file):
    with tf.io.gfile.GFile(pb_file, 'rb') as f:
        graph_def = tf.compat.v1.GraphDef()
        graph_def.ParseFromString(f.read())
    print("Tensors in the graph:")
    for node in graph_def.node:
        print(f"Name: {node.name}, Op: {node.op}")
        
if __name__ == "__main__":
    pb_path = "/home/ryan/SEP/code/Reconstruction/TACO-20250119T094850Z-001/TACO/reconstructed_TACO_graph.pb"
    inspect_pb_graph(pb_path)
```
Using this and Netron, we found the input tensor to be image_tensor:0 and the output tensors to be: detection_boxes:0, detection_scores:0, detection_classes:0, num_detections:0.

First we tried the following command to convert our .pb model into a .tflite one:

```
tflite_convert --graph_def_file=/home/ryan/SEP/code/Reconstruction/TACO-20250119T094850Z-001/TACO/reconstructed_TACO_graph.pb --output_file=/home/ryan/SEP/code/Reconstruction/model.tflite --input_arrays=image_tensor --output_arrays=detection_boxes,detection_scores,detection_classes,num_detections --input_shapes=1,300,300,3
```

This did not work as it turned out the model needed to be in SavedModel format to be converted. Then we went onto converting our model to SavedModel format.
