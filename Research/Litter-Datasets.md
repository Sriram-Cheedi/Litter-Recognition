|     Dataset     |         Description         |
| --------------- | --------------------------- |
|  [TACO](http://tacodataset.org/)     | An open image dataset containing thousands of annotated litter images in different environments (Free to use as long as cited)     |
|  [UAVVaste Dataset](https://github.com/PUTvision/UAVVaste)  | A dataset containing 772 images and 3718 annotations of litter, taken via drone. (Publically available, requires citation)       |
|  [Trashnet](https://github.com/garythung/trashnet)   | A dataset containing 2527 images of various types of litter categorised by material (Requires citation)     |
|  [TrashBox](https://github.com/nikhilvenkatkumsetty/TrashBox)| A dataset containing 17785 waste object images scraped from the web, however without annotations. (Requires citation)       |
|  [Open Litter Map](https://openlittermap.com/)   | A dataset containing over 100k images with 11 main categories and 187 subcategories. (Requires citation)      |
|  [Waste Datasets Review Repository](https://github.com/AgaMiko/waste-datasets-review) | A highly useful public Git repository containing various sources for obtaining litter datasets. |
